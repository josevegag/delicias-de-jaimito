# Las Delicias de Jaimito

Bilingual EN/ES restaurant website built with the Next.js App Router. The production domain is [www.deliciasdejaimito.net](https://www.deliciasdejaimito.net).

## Run locally

```bash
npm install
npm run dev
npm run build
```

The home page is `app/page.tsx`, its layout and metadata are in `app/layout.tsx`, and styles are in `app/globals.css`. Local image assets are in `public/images/`.
